# Assets

- `public/images/moon.webp`: optimized NASA LRO photographic lunar mosaic. Credit: NASA’s Scientific Visualization Studio. Source: https://svs.gsfc.nasa.gov/5001/ (1024px JPEG download). Used on a personal informational website under NASA’s media usage guidelines: https://www.nasa.gov/nasa-brand-center/images-and-media/. The warm tint is applied in CSS; this is a real photographic mosaic, not a historical engraving.
- `src/components/astronomy.tsx`: original decorative SVG project illustrations. These are contemporary graphics, not project screenshots or historical scans.
- Space Mono: Colophon Foundry, SIL Open Font License 1.1; locally served through `@fontsource/space-mono`.
- Silkscreen: Jason Kottke, SIL Open Font License 1.1; locally served through `@fontsource/silkscreen`.
- Interface icons: Lucide, ISC license.
- `design-reference.png`: user-supplied visual reference; not redistributed as a website asset.
